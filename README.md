# Banking Dashboard – Risk Analytics Project

End-to-end data analytics project focused on **Risk Analytics in Banking & Financial Services**.

### Project Highlights:
- Cleaned and analyzed banking client data (loans, deposits, credit cards, business lending)
- Performed Exploratory Data Analysis (EDA) using Python
- Loaded data into MySQL for structured querying
- Built interactive Power BI dashboards with key banking KPIs
- Analyzed client profiles by gender, nationality, occupation, income, and engagement length
- Identified patterns that help minimize lending risk

### Tools Used:
Python (Pandas, Seaborn) | MySQL | Power BI (DAX)

### Key Insights:
- Strong correlation between Bank Deposits, Checking Accounts, and Saving Accounts
- Clear view of Total Loan vs Total Deposit portfolio
- Client engagement and loyalty classification analysis
